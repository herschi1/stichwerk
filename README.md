# Stichwerk

Stickmuster im Browser gestalten – Text, Formen und SVG-Logos – und als PES exportieren.
Die direkte Bluetooth-Verbindung zur Brother PP1 folgt in Version 0.2.

Design embroidery patterns in the browser – text, shapes and SVG logos – and export them as PES.
Direct Bluetooth connection to the Brother PP1 follows in version 0.2.

- Online: `https://<benutzername>.github.io/stichwerk/`
- Browser: Chrome oder Edge am PC / Chrome or Edge on a PC
