# Stichwerk

Stickmuster im Browser gestalten – Text, Formen und SVG-Logos – und per Bluetooth direkt
an die Brother PP1 (SKiTCH) senden und sticken. PES-Export für andere Programme.

Design embroidery patterns in the browser – text, shapes and SVG logos – and send them to
the Brother PP1 (SKiTCH) via Bluetooth. PES export for other software.

- Online: https://herschi1.github.io/stichwerk/
- Browser: Chrome oder Edge am PC / Chrome or Edge on a PC
